RegattaView

Privacy and shared access

RegattaView shares sailing recordings, conversations, tracks, race notes, and comments with invited team members. Every account on the current access list can view the shared library. Team members can edit shared playlists and race-review labels. A comment name belongs to the Google account that registered it.

Sign-in and activity

Google provides sign-in. RegattaView uses your verified email address to check the access list. This browser stores an application session token so you stay signed in; use a separate browser profile on a shared device.

For security and operating costs, access logs record IP addresses, browser information, requested files, and sign-in activity. The operator can associate signed requests with your account. Identifiable server and access logs are retained for up to one year, subject to the storage service’s deletion processing time.

Recordings and processing

Recordings and analysis are stored in private AWS storage. Local transcription is available. When the operator explicitly enables cloud processing, audio may be sent to OpenAI for transcription and transcript text, speaker labels, and recording times may be sent to Anthropic for summaries. Those providers process the submitted content under the operator’s service arrangements.

Only upload recordings appropriate to share with the invited team and use cloud processing when the people recorded have agreed to that use. Some maps use OpenStreetMap tiles, so the tile provider receives network requests from your browser.

Access and removal

Contact the site operator to request access changes or removal of a recording or personal information. Files and comments are retained until removed by the operator; protected backup versions may remain after removal. Anyone with access can download or copy content, so access controls cannot recall copies already made.
