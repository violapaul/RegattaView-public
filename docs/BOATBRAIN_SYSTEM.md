## Data Flow

### NMEA 2000 → BoatBrain

1. Instruments broadcast PGN messages on NMEA 2000 network
2. BoatBrain receives via CAN/TWAI interface
3. Messages parsed by PGN-specific handlers
4. Boat state updated in memory
5. Raw messages logged to SD card (Actisense format)

### BoatBrain → iOS App (UDP)

1. App sends "hello" packet every 2 seconds
2. BoatBrain tracks client IP/port
3. BoatBrain sends binary boat state at 10Hz
4. App decodes and displays instruments

### BoatBrain → Browser (WebSocket)

1. Browser connects to `ws://192.168.4.1/ws`
2. BoatBrain sends JSON boat state at 4Hz
3. PWA renders instrument display

## Quick Reference

### Network

| Setting | Value |
|---------|-------|
| SSID | `BoatBrain` |
| Password | Per-device, from `Arduino/include/wifi_credentials.local.hpp` (generated by `Scripts/provision_wifi.py`; 16–63 chars, never committed) |
| AP IP | `192.168.4.1` |
| UDP Port | `101` |
| WebSocket | `ws://192.168.4.1/ws` |

### Data Rates

| Interface | Rate | Format |
|-----------|------|--------|
| UDP (iOS) | 10Hz | Binary |
| WebSocket (PWA) | 4Hz | JSON |
| SD Logging | ~20Hz | Actisense |

### Instruments

| Measurement | PGN | Units |
|-------------|-----|-------|
| Position | 129025 | degrees |
| COG/SOG | 129026 | degrees / knots |
| Heading | 127250 | degrees |
| Speed (water) | 128259 | knots |
| Depth | 128267 | meters |
| Wind (apparent) | 130306 | degrees / knots |
| Rudder | 127245 | degrees |

## Typical Usage

### At the Boat

1. **Power on BoatBrain**
   - Insert SD card (optional, for logging)
   - Connect to 12V power
   - Wait 5 seconds for boot
   - Screen shows boat state

2. **Connect iPhone**
   - Open BoatData app
   - App auto-joins BoatBrain WiFi
   - Instruments appear within seconds

3. **Sail**
   - Data logs to SD card
   - Phone displays live instruments
   - Walk around boat - auto-reconnects

### After Sailing

1. **Remove SD card** from BoatBrain
2. **Run processing pipeline**:
   ```bash
   python Scripts/race_upload.py
   ```
3. **View replay** at RegattaView web app

## Troubleshooting

### No WiFi AP

- Check BoatBrain has power
- Wait 5+ seconds after power-on
- Look for "BoatBrain" in WiFi list
- Check serial output for errors

### Phone connected but no data

- Verify app shows "BoatBrain" as WiFi
- Check BoatBrain screen shows valid data
- Restart app if needed
- Check debug view for connection status

### Phone keeps switching to home WiFi

- BoatBrain captive portal should prevent this
- If persistent: Settings > WiFi > [home network] > disable Auto-Join
- Verify BoatBrain firmware has captive portal code

### Stale/delayed data

- Check WiFi signal strength (walk closer)
- UDP is lossy - some packets may drop
- Verify BoatBrain is receiving NMEA data

## Development

### Building BoatBrain

```bash
cd Arduino/BoatBrain
pio run -e m5stack-cores3           # Build
pio run -e m5stack-cores3 -t upload # Flash
```

### Building iOS Apps

```bash
cd iOS
xcodebuild -scheme BoatData -destination 'platform=iOS,name=YourPhone' build
xcodebuild -scheme BoatStart -destination 'platform=iOS,name=YourPhone' build
```

### Deploying to Device

```bash
# Install
xcrun devicectl device install app --device YourPhone "/path/to/BoatData.app"

# Pull logs
xcrun devicectl device copy from --device YourPhone \
    --domain-type appDataContainer --domain-identifier foobar.BoatData \
    --source "Documents/logs" --destination /tmp/logs
```

### Testing Without Hardware

1. **BoatBrain test mode**: Long-hold screen on boot
   - Generates fake NMEA data
   - Useful for testing app connectivity

2. **Simulator**: iOS simulator can't do UDP easily
   - Use real device for testing
   - Or modify app for mock data
